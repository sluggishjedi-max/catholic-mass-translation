# V27.7 multilingual follow-up — 2026-09-11

## 같은 독서와 동일 문자열을 구분

한국 주교회의 2026-09-11 원문과 프로젝트에 수록된 대만 공식 전례 자료를 전체 본문으로 대조했다.

| 항목 | 판정과 처리 |
| --- | --- |
| 제1독서 | 같은 1코린 9,16-19.22-27. 한국어의 22b와 중국어의 22 전체는 병렬 표시하되 원문은 각각 보존한다. |
| 화답송 | 같은 시편 84(83), 같은 후렴과 네 연. 중국어 셋째 연에는 8절이 추가된다. 검토한 이 절 조합만 예외로 대응한다. |
| 복음 환호송 | 진리로 거룩하게 해 달라는 같은 문장. 중국어 인쇄 장절 若十七7,17은 보존하고 본문 의미로 연결한다. 若를 전역적으로 요한으로 단정하지 않는다. |
| 복음 | 루카 6,39-42, 정상 대응 유지. |
| 입당송 | 시편 119(118),137.124와 詠118,137.124를 명시된 이중 번호로 대응한다. |
| 영성체송 | 시편 42(41),2-3 / 요한 8,12의 두 공식 선택지. 중국어 或：와 본문에 붙은 장절을 분리하여 각 선택지를 양쪽 언어끼리 대응한다. |

단일 독서끼리는 같은 장의 같은 절 집합에 한해 세부 절 접미 차이를 허용한다. 원문에 명시된 긴/짧은 독서나 서로 다른 절 범위는 자동으로 합치지 않는다. 화답송의 임의 중첩 범위나 추측한 시편 번호 변환도 허용하지 않는다. 실제 한쪽 원문만 있는 선택지는 반대 열에 사용자가 누를 수 있는 AI 번역 버튼을 제공하며 결과에 AI 배지를 붙인다. AI 결과는 공식 원문 필드에 저장하지 않는다.

쉼표가 장 경계와 절 목록 양쪽에 쓰이는 모호한 인용은 완전하게 판별할 수 없다. 현재 점은 절 목록, 명시적 콜론은 장 경계로 보존하며 5,20-6,2 같은 역방향 끝점 쉼표 형식만 장 경계로 해석한다.

검토 출처: [한국 주교회의 매일미사](https://missa.cbck.or.kr/DailyMissa/20260911), countries/taiwan/taiwan_daily_mass_data.js의 원본별 source 메타데이터. 재현 도구: tools/audit-v27-7-daily-comparison.js.

## 기도 결구

기존 KR/VN/EN/JP/LA에 ZH/IT/PT/ES/DE를 연결했다. 본기도의 긴 결구와 예물기도·영성체 후 기도의 짧은 결구 각각에 대해 through_son, relative_son, addressed_son 세 형식을 구분한다. 원문에 이미 있는 결구의 표현과 형식을 우선 보존하고, 없는 번역 칸만 대응 공식으로 채운다. 결구는 본문과 별도 행에 두며 AI 번역 대상에서 제외한다.

- ZH: 수록 대만 공식 미사 원문의 결구(성체 성혈 대축일의 성자 호칭 형식 포함).
- IT: countries/italy/italy_mass.js에 수록한 공식 미사통상문의 결구 지침.
- PT: countries/portugal/portugal_mass.js의 세 결구 지침 및 [포르투갈 전례국](https://www.liturgia.pt/santos/santo_v.php?cod_santo=40). 기본 보충 표현은 포르투갈식이며 브라질 등 기존 원문 표현은 덮어쓰지 않는다.
- ES: 멕시코 미사통상문과 [스페인 주교회의 전례 자료](https://www.conferenciaepiscopal.es/wp-content/uploads/2022/03/Jornada-por-la-Vida-2022-subsidio-liturgico-para-el-celebrante.pdf). 지역별 기존 문장·구두점은 보존한다.
- DE: [독일어권 전례연구소의 세 결구 안내](https://www.liturgie.ch/praxis/regeln-infos-orientierung/wie-was-macht-man/471-gebetsanrede), [파사우 교구](https://www.bistum-passau.de/beratung-seelsorge/ehe-partnerschaft/die-trauung-gestalten). SCHOTT의 축약된 본기도 결구는 긴 형식으로 확장한다.

검증 범위: 10개 언어 × 3개 기도 × 3형식 = 90개. 인식, 본문 분리, 반복 적용 시 중복 없음, 결구 AI 없음. 모든 날짜·지역의 철자 변형을 전수 검증한 것은 아니다.

## 본문 소스 편집

국가별 미사통상문·기도·성가 51개와 공통 고유 기도 및 대만 매일미사 본문 2개, 총 53개 파일을 정리했다. 27,653개 다문장 문자열을 문장/기존 줄바꿈/HTML br 경계에서 나눠 문자열 결합으로 표현한다. 실행 시 본문·공백·HTML·배열 구조는 바뀌지 않는다.

도구: node tools/format-liturgical-sentences.js (미리 검증), --write (적용).
Playwright에 포함된 Babel 구문 분석기를 사용하며 적용 전후 문자열 결합을 정규화한 AST의 SHA-256이 같은 경우에만 저장한다. 국가별 원본/편집용 본문의 중복 필드는 자동 동기화되는 것은 아니므로 각각의 source 메타데이터와 편집 도구도 확인해야 한다.
