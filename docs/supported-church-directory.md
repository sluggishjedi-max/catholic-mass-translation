# 지원 국가 성당 정보 보완

공식 교구 주소록에서 확인한 이름·주소·연락처·미사시간·사제 이름과 지도 좌표를 국가별 `*_churches.js`에 저장한다. 이번 보완 대상은 저장된 성당이 없거나 주교좌성당만 등록된 미국, 아일랜드, 스코틀랜드, 필리핀이다. 전국의 모든 성당을 수록한 자료가 아니며 기존 다른 교구·북아일랜드 주교좌성당 자료도 보존한다.

2026-10-12 보완으로 성당 794곳을 추가했다. 반영 후 미국 401곳, 아일랜드·북아일랜드 261곳, 스코틀랜드 95곳, 필리핀 50곳이며, 이 중 공개 미사시간을 저장한 성당은 총 591곳이다.

## 공식 출처

- [더블린 대교구 본당 주소록](https://www.dublindiocese.ie/parishes/parishes-a-z/): 본당별 성당과 각 성당의 미사시간, 본당 연락처·담당 사제, 교구가 공개한 지도 좌표. 성당 상세정보가 없는 본당은 수집 보고서에 별도 기록한다.
- [글래스고 대교구 본당 주소록](https://www.rcag.org.uk/index.php/the-archdiocese/parishes): 성당별 주소·미사시간과 공개된 담당 사제. 다른 사제의 거주지 연락처와 팩스는 대표 전화로 사용하지 않는다.
- [워싱턴 대교구 성당 검색기](https://adw.org/parishes-masses/parish-mass-finder/): 이름·주소·지도 좌표. 상세페이지에서 HTTP 403 오류가 발생해 연락처·미사시간은 추가하지 않는다.
- [로스앤젤레스 대교구 성당 검색기](https://lacatholics.org/find/): 공개 검색기의 전체 페이지와 공식 성당 상세페이지. 주간 미사시간과 언어를 보존하며 과거 본당 역사에 나오는 사제 이름과 과거 연도의 의무 축일 일정은 가져오지 않는다.
- [쿠바오 교구 본당 목록](https://dioceseofcubao.ph/parishes/): 지구별로 반복된 목록을 중복 집계하지 않고 교구 대리구별 목록을 사용한다. 공식 상세페이지가 있는 [쿠바오 주교좌성당](https://dioceseofcubao.ph/immaculate-conception-cathedral-of-cubao/)에는 주소·연락처·담당 사제·미사시간을 추가한다. 다른 본당의 주소나 시간표는 추정하지 않는다.

## 갱신과 검사

Python의 `requests`, `beautifulsoup4`와 프로젝트 Node/Playwright 환경을 사용한다.

```sh
npm run church:supported:refresh
npm run church:supported:check
```

`--countries IE,GB-SCT,US,PH`로 범위를 지정할 수 있고 `--dry-run`은 파일을 쓰지 않는다. `--refresh` 없이 실행하면 24시간 이내의 임시 캐시를 재사용한다. 모든 선택 국가의 주소록 수집이 끝난 다음 데이터를 기록하며 상세페이지 연결 실패는 보고서에 남긴다.

[반영 수와 미확인 상세페이지](supported-church-enrichment.json)에는 이전·이후의 성당 수, 항목별 공개 정보 수, 공식 출처별 조회 결과와 한계를 기록한다. `directoryCheckedAt`은 수집 확인일이며 원 출처의 작성·수정일을 뜻하지 않는다. 공개된 미사시간은 변경될 수 있으므로 연결된 공식 출처에서 다시 확인한다.

이름이 같은 성당도 공식 상세페이지가 다르면 별도로 보존한다. 새로운 국가·언어에도 기존 공통 성당 검색·상세보기 경로를 그대로 사용한다. 현재 상세 필드가 없는 성당과 이번에 다루지 않은 교구·국가의 누락은 이후 보완 대상이다.

공식 출처가 임시 폐쇄를 공지한 성당에는 상태와 공지 링크를 별도로 저장하고 공통 상세화면에서 지원 언어로 표시한다. 같은 본당의 다른 성당에서 봉헌하는 미사시간을 폐쇄된 성당의 시간표로 넣지 않는다. 짧은 계절별 시간표 예외도 출처와 함께 표시한다.
